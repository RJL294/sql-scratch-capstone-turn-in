# Some Good News

A feel-good news aggregator in the style of a classic news front page. Every
article lives as **data** — either a curated entry in `data/articles.json` or an
item pulled from a public RSS/Atom feed — and the homepage and section pages are
**generated** from that data. We never republish anyone's work: each headline
links straight to the original source.

The design is the provided mockup, extracted into `assets/styles.css` and
`assets/main.js` and rendered from templates so it stays identical everywhere.

## Quick start

```bash
cd some-good-news

npm run fetch    # (optional) pull RSS feeds in feeds.json → data/feed-cache.json
npm run build    # generate the site into dist/
npm run serve    # preview at http://localhost:4173
# or: npm run dev   (build + serve in one step)
```

No dependencies, no install step — it runs on plain Node 18+.

## How it works

```
feeds.json ─┐
            ├─ npm run fetch ─→ data/feed-cache.json ─┐
            │                                          ├─ npm run build ─→ dist/
data/articles.json (curated) ─────────────────────────┘                    index.html
data/home.json (homepage layout) ──────────────────────────────────────────  kindness.html, animals.html, …
```

1. **`scripts/fetch-feeds.js`** downloads each feed in `feeds.json`, parses it
   (zero-dependency parser in `lib/rss.js`), normalizes the entries, and caches
   them to `data/feed-cache.json`. Fetching is decoupled from building, so the
   build is deterministic and works offline from the last fetch.
2. **`scripts/build.js`** loads every source via `lib/articles.js`, which
   normalizes, dedupes (by URL, then slug), and sorts everything into one list.
   It then renders the homepage and one page per category into `dist/`.

## Adding content

### Curate a story by hand

Add an object to `data/articles.json`:

```json
{
  "title": "Headline goes here",
  "dek": "One or two sentence summary.",
  "category": "kindness",
  "source": "Where you found it",
  "url": "https://original-source.example.com/story",
  "hoursAgo": 3
}
```

Only `title`, `url`, and `category` really matter. Optional fields:

| Field         | Purpose                                                            |
|---------------|-------------------------------------------------------------------|
| `dek`         | Short summary shown under the headline                            |
| `glyph`       | Emoji used as placeholder art (defaults to the category's)       |
| `gradient`    | `["#hex","#hex"]` background behind the glyph                     |
| `publishedAt` | ISO date; or use `hoursAgo` to keep demo content fresh           |
| `featured`    | `true` makes it the lead splash story                            |
| `rail`        | `true` puts it in the "More good news" rail                      |
| `tags`        | Strings that homepage sections pull from (see `data/home.json`)  |
| `kicker`      | Override the little label above the headline                     |
| `readingTime` | e.g. `"3 min read"`                                              |

### Pull from a feed

Add to `feeds.json` and re-run `npm run fetch && npm run build`:

```json
{ "url": "https://example.com/feed/", "source": "Example", "category": "community" }
```

Every item from that feed is filed under the given category.

## Project layout

```
some-good-news/
├── feeds.json            # RSS/Atom feeds to ingest
├── data/
│   ├── articles.json     # curated stories (source of truth)
│   ├── home.json         # homepage sections, ticker, meter
│   └── feed-cache.json   # generated by `npm run fetch` (gitignored)
├── lib/
│   ├── categories.js     # category list + default look (drives the nav)
│   ├── articles.js       # load + normalize + dedupe + sort
│   ├── rss.js            # zero-dependency RSS/Atom parser
│   ├── util.js           # escaping, dates, truncation helpers
│   └── render.js         # HTML templates (the mockup, parameterized)
├── assets/               # styles.css + main.js (copied into dist/)
├── scripts/
│   ├── fetch-feeds.js    # npm run fetch
│   ├── build.js          # npm run build
│   └── serve.js          # npm run serve
└── dist/                 # generated site (open dist/index.html)
```

## Categories

`kindness`, `animals`, `everyday-heroes`, `science-wins`, `good-ai`,
`the-planet`, `community`, `comebacks`, `reunions`. Edit `lib/categories.js` to
add, rename, or restyle them — the nav and section pages update automatically.

## Deploying

`dist/` is a fully static site. Point GitHub Pages, Netlify, or any static host
at it (or at the repo with a build command of `npm run build` and publish
directory `some-good-news/dist`).

## A note on sourcing

Some Good News links out to original reporting and shows only a headline and a
short summary. The bundled `data/articles.json` contains illustrative sample
stories with `example.com` links; replace them with real, attributed stories or
feed content before publishing.
